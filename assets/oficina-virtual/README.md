# Imágenes de Oficina Virtual

Sube las fotos de Oficina Virtual a esta carpeta en formato WebP real (`.webp`).

## Nombres de archivo

- Imagen principal: `oficina-virtual-01.webp`.
- Imágenes adicionales: `oficina-virtual-02.webp`, `oficina-virtual-03.webp`, y así sucesivamente.

Usa exactamente este formato: minúsculas, sin espacios ni tildes y numeración de dos dígitos.

## Recomendaciones

- Dimensiones: 1200 × 1200 píxeles.
- Peso: idealmente menos de 300 KB por imagen.
- Elemento principal centrado, con espacio alrededor para permitir el recorte en móvil.
- Evita incluir texto en la imagen: la sección ya muestra tarjetas superpuestas.

La carpeta queda preparada para cargar las fotos. Su incorporación visual al sitio se realizará después de subirlas.
