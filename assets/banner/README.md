# Banner de inicio

Sube la imagen a esta carpeta con el nombre exacto:

`banner-inicio.webp`

Ruta completa: `assets/banner/banner-inicio.webp`.

- Formato: WebP real, con extensión `.webp`.
- Tamaño recomendado: 2400 × 1350 píxeles.
- Peso recomendado: menos de 500 KB.
- Mantén el elemento principal cerca del centro y deja la zona izquierda despejada para el título.
- Evita incluir texto dentro de la imagen.

El banner se recorta para adaptarse a cada pantalla, especialmente en móvil, y el sitio aplica una capa oscura encima. Usa una imagen con buena iluminación.

Esta carpeta prepara la carga del archivo. La imagen debe conectarse al fondo del banner del sitio después de subirla.
